## 🙌 Contributing to Dokandar

Thank you for considering contributing to **Dokandar** – a lightweight inventory management app built for small businesses, using Flutter.

We welcome contributions of all kinds — code, design, documentation, bug reports, ideas, and feedback.

---

### 🚀 Getting Started

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/your-username/dokandar.git
   cd dokandar
   ```
3. **Install dependencies:**
   ```bash
   flutter pub get
   ```
4. **Run the app:**
   ```bash
   flutter run
   ```

---

### 🛠️ What You Can Contribute

- 🧠 New feature ideas
- 🐞 Bug reports or fixes
- 🧪 UI/UX improvements
- 📄 Better documentation
- 🔍 Code optimization or refactoring

---

### 📌 Guidelines

- Follow clean code practices and Flutter best practices.
- Try to write meaningful commit messages.
- Create a new branch for each feature or fix:
  ```bash
  git checkout -b feature/your-feature-name
  ```

---

### ✅ Submitting a Pull Request

1. Push your changes to your fork.
2. Open a **Pull Request** with a short description.
3. Tag it appropriately: `feature`, `bugfix`, `docs`, etc.
4. Wait for review & feedback. 😄

---

### 💬 Need Help?

If you're unsure about anything, feel free to open an issue or message the maintainer.
