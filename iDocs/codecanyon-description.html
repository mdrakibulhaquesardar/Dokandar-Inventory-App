BizDash is a pure Flutter UI Kit for building modern business, admin, and management applications. It provides ready-made screens, dashboard layouts, and reusable components – all powered by static mock data.

Important: This is a UI template only. It is not a complete app, not a SaaS, and not a ready-made business solution.

Key UI Screens (Included)

  • Login screen (UI only)
  • Forgot Password screen (UI only)
  • Main Dashboard
  • Records List (generic items/records)
  • Create / Edit Record (forms & bottom sheets)
  • Reports & Analytics (summary tiles & filters with mock data)
  • Profile screen
  • Settings screen (theme, language, toggles)
  • Notifications screen
  • Components Showcase screen
  • Empty & Error States (no data / no internet / error)
  • Search & Filter (modal / bottom sheet)

What You Get

  • Beautiful dashboard screen with cards & stats (mock data)
  • Generic records list screens
  • Contacts / partners / team list UIs
  • Expense & basic report summary UIs
  • Profile, settings & support screens
  • Login & setup screens (UI only, no auth)
  • Components & states showcase screen
  • Reusable widgets & consistent design system

What Is NOT Included (Very Important)

  • No backend / server
  • No database or local storage (no Isar, SQLite, etc.)
  • No authentication logic (login is just UI)
  • No POS / checkout / billing / payment logic
  • No real reporting engine
  • No real PDF invoice generation (only basic UI parts)
  • No real data backup / restore

All the numbers, charts, and lists you see in the screenshots are driven by mock data only. Buyers must connect their own backend or local database to make it functional.

Target Audience

  • Flutter developers
  • Startup teams & SaaS builders
  • Freelancers building admin panels
  • Designers who need a working Flutter UI reference

Tech Stack

  • Flutter 3.x / Dart 3.x
  • GetX (navigation & simple state)
  • Custom light / dark theme
  • Localization-ready (Bengali & English example)

Folder Structure

lib/

├─ app/

│  ├─ config/       (config & theme)

│  ├─ data/         (plain Dart models, no DB)

│  ├─ modules/      (feature UIs: dashboard, records, settings, etc.)

│  ├─ routes/       (navigation)

│  ├─ utils/        (helpers)

│  ├─ views/        (main shell)

│  └─ widgets/      (reusable UI)

├─ mock/            (mock_data.dart, mock_data_service.dart)

└─ l10n/            (localization)

How to Use

  1. Open the project in Android Studio or VS Code
  2. Run flutter pub get
  3. Run flutter run on an emulator or device

All data is static and lives in lib/mock/mock_data.dart. You can replace this file with your own repository/API integration.
