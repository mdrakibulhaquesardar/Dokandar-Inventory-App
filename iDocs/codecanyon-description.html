Dokandar Inventory is a mobile inventory management application that works with Android devices. It is built with Flutter, a fast and powerful framework for creating beautiful cross-platform apps. Perfect for small to medium businesses, retail stores, and shop owners who need a comprehensive solution to manage products, track sales, handle customers, and generate invoices - all offline without requiring internet connectivity.

Check the screenshots section below for app preview images showing all features and screens.

Dokandar Inventory provides a complete inventory management solution with modern UI and powerful features.

Installation

Complete installation guide is included in the documentation. Quick setup steps:

  1. Extract the downloaded package
  2. Open the project in Android Studio or VS Code
  3. Run flutter pub get to install dependencies
  4. Connect an Android device or start an emulator
  5. Run flutter run to launch the app

Requirements:

  • Flutter SDK 3.5.4 or higher
  • Dart SDK 3.x
  • Android Studio 2022.3+ or VS Code 1.80+
  • JDK 17
  • Android SDK (API 21 to 35)

Key Features

With Dokandar Inventory, you can manage your business with ease and efficiency. Some of the features are:

Inventory Management: You can manage your products with SKU tracking, organize them into categories, track stock levels in real-time, and receive automatic alerts when stock runs low.

Sales Counter & POS: You can process sales with a simple and intuitive interface, manage cart items, apply discounts and taxes, accept multiple payment methods, and track due payments.

Invoice System: You can generate professional PDF invoices instantly, preview them in full-screen, print directly, or share via email, WhatsApp, and other apps.

Customer & Supplier Management: You can maintain complete databases of customers and suppliers, track due payments, payment history, and contact information.

Reports & Analytics: You can monitor your business performance, track sales, inventory, and expenses, and generate reports with daily, weekly, monthly, or custom date ranges.

Expense Tracking: You can track and categorize your business expenses, and see how they affect your profit.

Employee Management: You can manage employee records and track salaries.

Data Backup & Restore: You can export all your data to JSON format and restore from backup files whenever needed.

Multi-Language Support: You can use the app in Bengali or English with easy language switching.

Theme System: You can choose between Light, Dark, or System theme for comfortable viewing.

Technical Specifications

Framework: Flutter 3.5.4+ / Dart 3.5.4+

Architecture: MVC (Model-View-Controller) pattern with GetX 4.7.2 for state management

Database: Isar Database 3.1.0 (local NoSQL, offline-first)

Platform Support: Android 5.0+ (API 21), Target SDK: API 34 (Android 14)
